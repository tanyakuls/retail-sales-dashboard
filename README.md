# Retail Sales Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze retail sales performance and identify key business trends.

## Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Quantity

## Key Analysis

- Monthly sales trends
- Category performance
- Regional performance
- Product performance
- Profitability analysis

## Key Insights

- Identified top-performing product categories.
- Compared sales and profitability across regions.
- Analyzed monthly trends to understand business performance.
